

Welcome & Overview
In the previous lesson, we learned that programming is about giving a computer clear instructions to solve a problem.

Now we need to answer a simple question: What do we use to give those instructions?

We use a programming language. Python is one of those languages.

This lesson is simply about understanding what Python is and why we have chosen it for this course. We are not learning Python syntax yet, and we are not discussing all the things Python can be used to build.

 


What Is Python?
Python is a high-level, general-purpose programming language.

That definition may sound complicated, so let's break it down.

Python is a programming language
You already know that a language helps people communicate.

English allows people to communicate with people.
Python allows us to communicate instructions to a computer.

Giving instructions
Imagine you want someone to calculate the total cost of your shopping. You might say:

"Add ₦5,000, ₦3,000, and ₦2,000 together."

The person understands your instruction and gives you the answer. Python allows you to express instructions like this in a form that a computer can execute.

So, in simple terms: Python is a language we use to give instructions to computers.

 

 


Why Do We Need a Programming Language?
You might ask:

"Why can't I just tell the computer what I want in normal English?"

Because computers don't naturally understand human instructions in the same flexible way people do. Imagine telling a very literal assistant: "Prepare my food."

The assistant might ask:

What food?
How much?
Which ingredients?
How should it be prepared?
A human might make reasonable assumptions. A computer doesn't simply fill in those gaps. You need to express your instructions according to rules that the computer can process. A programming language gives us those rules.

A translator
Imagine you speak English and the other person speaks only French. You have an idea you want to communicate, but you need a language both sides can understand.

Think of Python as part of that communication process:

Your idea → Python instructions → Computer
Python gives you a structured way to turn your ideas into instructions.

 


What Does "High-Level" Mean?
Python is called a high-level programming language. This does not mean "better" or "more advanced." It means Python allows programmers to work without dealing directly with many of the complicated details of computer hardware.


Using a car
When you drive a car, you use:

the steering wheel
the brake
the accelerator
the gear
You don't need to understand exactly how fuel is injected into the engine or how every tiny component moves. You simply use the controls. The complicated work happens underneath.

Python works in a similar way. You can tell the computer "Calculate this number" without having to manually tell the computer how its processor should perform every tiny operation.

Remember: High-level means Python hides many low-level computer details so that programmers can focus more on solving problems.


What Does "General-Purpose" Mean?
Python is also general-purpose. This simply means Python isn't designed for only one specific type of task.

A multipurpose kitchen
Imagine you have a kitchen. You can use it to:

cook rice
make tea
bake a cake
prepare soup
The kitchen isn't designed for only one meal. Python is similar. It is a general-purpose programming language that can be adapted to many different kinds of programming tasks.

You don't need to learn those different tasks now. The important point is simply: Python is flexible rather than being limited to one particular purpose.

 


Why Learn Python?
Now we get to the second half of the lesson. There are many programming languages. So why learn Python?

There are several good reasons:


1. Python is readable
One of Python's most noticeable characteristics is that its code is relatively easy for humans to read. Consider this:

message = "Hello, Python!"
print(message)
If you have never programmed before, you may not understand exactly how it works yet. That's completely fine. But you can probably recognize that there is a message and that something is being done with that message.

The output would be:

Hello, Python!
The purpose of showing this example isn't to teach you variables or print() yet. It's simply to let you see that Python code can be written in a form that is relatively readable.

Clear instructions

Imagine two people give you instructions.

Person A says: "Go straight, turn left at the junction, and the shop is on your right."
Person B gives you a page full of complicated symbols.
Even if both instructions are technically correct, Person A's instructions are easier for you to understand. Python aims for this kind of readability.


2. Python Reduces Unnecessary Complexity
This is an important point. You may hear people say: "Python is the easiest programming language." That's not quite accurate. Python can still be challenging.

You still have to learn:

how to think logically
how to solve problems
how to understand errors
how to structure programs
how to write correct instructions
Python doesn't remove those challenges. What it does is reduce some unnecessary complexity in the way you express your instructions.

Automatic vs Manual Car

Imagine learning to drive.

With a manual car, you have to think about steering, braking, accelerating, changing gears, and controlling the clutch.
With an automatic car, some of that complexity is handled for you.
You still have to learn how to drive. But you can focus on the more important parts of driving without having to manage the gear changes yourself.

Python is somewhat similar. It doesn't make programming effortless. It simply allows beginners to focus more quickly on programming concepts and problem-solving instead of being overwhelmed by unnecessary syntax.


3. Python Has a Large Community
Another reason to learn Python is its large community. Imagine you're learning something new and you get stuck. Would you rather have:

One person who knows how to help you?
Millions of people who have learned and used the same language?
Python has a very large community. This means there are many:

tutorials
books
courses
videos
discussions
examples
documentation
A huge classroom

Imagine learning in a classroom with millions of students. Someone has probably asked a question similar to yours before. Someone may have already written an explanation or created an example. This makes learning and finding help much easier.

(Of course, you should learn to understand solutions rather than blindly copy them.)


4. Python Has a Large Ecosystem
Python also has a large ecosystem. For now, don't worry about the technical meaning of "library." Think of a library as a collection of ready-made tools that other programmers have created for Python.

A toolbox

Imagine buying a toolbox. You have some basic tools inside. Later, you discover that you need a special tool for a particular job. Instead of manufacturing that tool yourself, you can get one that someone else has already made.

Python works similarly. There are many tools available that extend what you can do with Python. This means you don't always have to build everything from scratch.


5. Python Is Widely Adopted
Another reason to learn Python is that it has been widely adopted by individuals, organizations, educators, researchers, and software developers.

That matters because learning a widely used language gives you access to:

a large body of existing code
many learning materials
established tools
a large developer community
many opportunities to practise your skills
Think about learning a language spoken by millions of people. It gives you more opportunities to communicate than learning a language spoken by only a handful of people. Python's large user base provides a similar advantage.

 


Why Python for This Course?
At this point, you might ask:

"So why did we choose Python for this curriculum?"

The answer is simple. We want you to learn programming, not spend your early learning experience fighting unnecessary complexity.

Python gives us a readable language with:

relatively simple syntax
a large community
a large ecosystem
extensive learning resources
That gives us a good environment in which to develop your programming skills.

Remember: We are learning Python because it is a useful tool for learning programming concepts and solving problems—not because you need to memorize hundreds of Python commands.

 


The Big Picture
Let's put everything together.

What is Python? Python is a high-level, general-purpose programming language used to give instructions to computers.
Why is it called high-level? Because it hides many complicated hardware details and lets programmers work with higher-level concepts.
Why is it called general-purpose? Because it is flexible and can be used for many different kinds of programming tasks.
Why learn it? Because Python is relatively readable, reduces unnecessary syntax complexity, has a large community, has a large ecosystem of tools, has extensive learning resources, and is widely adopted.
And perhaps the most important reason for a beginner: Python allows you to spend more time learning how to think like a programmer and less time struggling with complicated syntax.

 


A Simple Mental Model
If you remember only one analogy from this lesson, remember this:

Python is like a language and a toolbox combined.

The language allows you to communicate instructions to the computer.
The toolbox represents the many tools and libraries available to help you solve different problems.
Your job as the programmer is to learn how to use that language and those tools to solve problems.
